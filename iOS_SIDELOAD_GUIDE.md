# iOS Sideloading Guide for Nuvio Mobile Ultra

## Option 1: AltStore (Mac)

1. Download from https://altstore.io
2. Move to Applications
3. Sign in with Apple ID
4. Connect iPhone via USB
5. Drag NuvioMobile.ipa onto AltStore icon

## Option 2: Sideloadly (Windows/Mac)

1. Download from https://sideloadly.io
2. Install and launch
3. Sign in with Apple ID
4. Connect iPhone
5. Select IPA file
6. Click Install

## Downloading from GitHub Actions

1. Go to Actions tab in your repo
2. Find "Build iOS IPA" workflow
3. Click the latest run
4. Download NuvioMobile.ipa from Artifacts

## After Installation

- Settings > General > VPN & Device Management
- Trust the developer certificate
- Open Nuvio Mobile Ultra app

## 7-Day Refresh

Free certificates expire after 7 days. Re-sideload to refresh.
